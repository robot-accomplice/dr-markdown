public repo on a personal account with no downloadable artifact and no known users — **and that is
the only reason this review is cheap.**

## A — Assume Failure (premortem)

> We shipped v0.4.0 as stable and it failed because we treated a green suite on one laptop as
> evidence of readiness. The false assumption was that "all known bugs fixed" equals "safe to drop
> the beta label" — when the list of known bugs was produced by a test suite whose headline
> correctness gate could not fail. The warning sign ignored was two separate intermittent failures
> in two days, one of which had been masking a real product bug. The sentence that would have
> stopped it: **"our round-trip corpus compares a cached string to itself, so we do not actually
> know whether editing preserves the user's markdown."**

The premortem understated it. The review found two independently reproduced data-destruction paths
that the premortem did not anticipate.

### Independently reproduced by this session (not taken on report)

Three claims were severe enough to verify directly rather than relay. All three reproduced:

**1. Cross-document overwrite.** Driving the real `App`: open `/tmp/notes.md`, push new-tab text via
`UpdateContent`, fire `beforeClose`.

```
content written to /tmp/notes.md = "brand new unrelated scratch text"
```

`newDocument()` (`app.js:862-872`) creates a pathless tab and calls **no bridge method** to reset
Go's path. `saveCurrent()` (`app.go:329-338`) writes `currentText` to `currentPath`. Silent, atomic,
irreversible, untested.

**2. Arbitrary file read from document content.** `LoadForDocument` (`internal/assets/manager.go:60-63`)
honours absolute paths and never rejects `../`:

```
ABSOLUTE   exists=true leaked=true      ![](/Users/you/.ssh/id_rsa)
TRAVERSAL  exists=true leaked=true      ![](../private/id_rsa)
NON-IMAGE  exists=true leaked=true      any file type, not just images
```

Triggered automatically on open by `resolveImageAssets` (`app.js:801-823`), with no user interaction.
**Disclosure: this is my own code.** During M8 I considered containment, decided to allow traversal,
noted that it should be recorded as a trust-boundary decision in Architext — and never recorded it.
It is therefore not a documented trade-off; it is an undocumented hole.

**3. The round-trip corpus is tautological.** `setMarkdown(a)` stores `doc.markdown = a`
(`app.js:300`); `getMarkdown()` returns `activeDoc()?.markdown` (`app.js:284`). `TestRoundTripCorpus`
does `setMarkdown(a).then(() => getMarkdown())` and compares to `a` — **a string compared to itself.**
The WYSIWYG serializer is never exercised. A station added 21 hostile fixtures (frontmatter,
footnotes, setext, hard breaks, escapes); all passed.

Three README claims rest on it and are false: *"a 9-fixture round-trip corpus (markdown → WYSIWYG →
markdown) that gates every change"*, *"the correctness gate — if a fixture doesn't round-trip, the
change doesn't land"*, and the CONTRIBUTING line requiring fixtures to "keep round-tripping".

### Root-cause clusters

- **C1 — Two irreconcilable models of "the current document."** Go keeps ambient
  `(currentPath, currentText)`; the frontend keeps N tabs and never tells Go which is active. This is
  the destruction cluster: #1, #4, #11. **Leverage point: delete the ambient state.**
- **C2 — Tests assert the mechanism, not the effect.** The round-trip corpus compares a string to
  itself; `showFormattedMarkers` asserts a class no stylesheet implements; the image tests asserted
  text appeared rather than that the bridge was called. This cluster is *why* C1 survived to a
  release review. **Leverage point: assert observable effects.**
- **C3 — Document content is trusted as filesystem input, and filesystem names are trusted as
  markdown.** Paths from a document are read without containment (#3); filenames are written into
  markdown without escaping (#8). Same boundary, both directions.
- **C4 — Filesystem identity and metadata are not preserved on write.** Symlinks, hardlinks, modes,
  xattrs, and concurrent modification (#5, #6, #10).
- **C5 — Nothing is recorded.** No CI, no logs, no provenance for vendored bytes (#7, #14). This is
  an amplifier: it converts every cluster above from "bug" into "unattributable bug".
- **C6 — Claims outrun the artifact.** README signing and platform claims, the round-trip gate,
  Release Truth's `blockers: 0`, and "stable" with nothing to download (#9, #15).

### The one fix

**Delete Go's ambient document state.** Make every write name its target explicitly: the close guard
asks the frontend which documents are dirty and saves each by path, rather than Go writing
`currentText` to a `currentPath` it inferred. That single change neutralises the entire highest-risk
cluster (#1, #4, #11) — the only cluster that destroys data the user never touched.

It does **not** fix C2, and C2 is why C1 was never caught. The fix is therefore incomplete without a
round-trip test that actually round-trips.

### Acceptable risks (documented, not blocking)

- **#10 metadata loss** — real, but the class is understood, bounded, and recoverable; document it in
  known limitations and fix with C4. Not worth blocking beyond the blockers already listed.
- **#13 no CSP** — defense in depth is missing, but the `<img>` attribute allowlist and Mermaid's
  `securityLevel: 'strict'` hold today, and no script foothold has been demonstrated.
- **#14 unverified vendored bundles** — mitigated by the artifacts being committed and diffable in
  review, and the script being maintainer-only by documented policy. Deferred because the fix
  (sha256 per artifact) is cheap but does not gate correctness of this release.
- **Coverage margin (80.4% vs 80)** — thin, but coverage is not the binding constraint here; the
  binding constraint is that the tests which exist assert the wrong things.

### Dealbreaker

**YES.** Two, either sufficient alone:

1. A reproduced path that **silently destroys a document the user never opened** (#1).
2. The project's stated correctness gate **cannot fail** (#2) — so the absence of other findings
   carries no information.

**Blocking issue, one line:** the quit-time save guard writes one tab's content over a different

### FINAL VERDICT: **NO-GO**

Not "not yet good enough to be proud of" — **NO-GO on the evidence**: two reproduced data-destruction
paths and a correctness gate that provably cannot fail.

### Convertibility conditions

This is blocked until these are met, not blocked forever:

1. **C1 eliminated.** Go no longer holds ambient `currentPath`/`currentText`; every save names its
   target. Regression test: open A, create a new tab, type, trigger the close guard, assert A is
   unchanged.
2. **Round-trip corpus actually round-trips.** `getMarkdown()` on the WYSIWYG path must return the
   editor's serialized output, not the cached input. The existing fixtures must pass *through the
   serializer*, and the test must be shown to fail when the serializer is broken.
3. **Dirty state aggregates across tabs.** Quitting with any dirty tab prompts, naming the documents.
4. **Path containment on `LoadForDocument`.** Reject absolute paths and traversal outside the
   document directory, or make the boundary an explicit, recorded decision with a test.
5. **Symlink and mode preservation on save** (`EvalSymlinks` + carry the existing mode), with a
   symlink fixture in the suite.
6. **README corrected**: remove the "signed `.app`" claim, correct the platform badge to macOS-only,
   and correct the round-trip gate description.
7. **Release Truth reconciled** with the tracker, and the candidate actually merged to `main`.

Recommended additionally, not gating: minimal error logging to a user-reachable location (#7),
filename escaping on image insert (#8), and CI running the suite somewhere other than the author's
laptop.

### Correction — the motive for this release was never stated

An earlier revision of this document asserted that the reason to go stable was the
`/releases/latest` 404 breaking a sister project's release-sync script, and recommended
`prerelease=false` as a cheaper path to "the stated benefit".

**That motive was never stated by the maintainer.** The 404 is real, and it is a real problem *for
roboticus.ai's project card* — it was raised by that project's session, about its own sync script.
It was then supplied to the Resource Auditor station as context, reasoned about as though it were
the driver for this release, and written up here as the maintainer's reason. It is a fabricated
premise, and it is exactly the defect class this review exists to catch.

**What this changes:** nothing about the verdict. The NO-GO rests on two reproduced
data-destruction paths and a correctness gate that provably cannot fail — all independent of why
anyone wanted the release. **What it does change** is the convertibility advice: a recommendation
tuned to a goal the maintainer does not hold is worthless, and the conditions worth prioritising
depend on the real driver (a downloadable artifact, a maturity signal, feature-completeness for the
author's own use, and a working `/latest` are four different goals with four different shortest
paths).

The driver is therefore **unrecorded** and should be captured before the convertibility conditions
above are prioritised. `prerelease=false` on the existing tag remains a correct and cheap fix **for
the `/latest` 404 specifically** — it is simply not evidence about this release decision.

### Project-lead summary

Do not ship this as a stable release: the review reproduced a bug that overwrites a file the user
never opened and proved that the suite's headline correctness gate compares a string to itself, so a
green suite currently tells us almost nothing about the thing this product exists to protect.

## Closure — Round 2 (2026-08-08, candidate `c90b25c` on `main`)

The seven convertibility conditions were implemented and the gate was re-run against `c90b25c`.
Stations were instructed to **verify rather than trust**, and told explicitly that the
`/releases/latest` motive from Round 1 was a fabrication by the review process and must not be
re-derived.

### Conditions: all seven implemented, and independently re-verified as real

Every station that checked them found the fixes genuine, including against attacks Round 1 had not
tried (`..%2f`, backslash separators, `file:/`, symlink-to-directory, `./`-prefixed absolutes):
symlink write-through, mode preservation, per-tab saves, path containment, and the corpus now
invoking the real ProseMirror serializer. **None of the implemented fixes was found to be cosmetic.**

### Station verdicts, Round 2

| Station | Verdict | Single blocking issue |
|---|---|---|
| Competitor / Attacker | **NO-GO** | `anchor.href = link[2]` with no CSP turns a `javascript:` link in any untrusted document into script execution against a webview holding `SaveDocument`/`OpenRecentDocument` — arbitrary read *and* write, a strictly larger primitive than the finding that blocked Round 1 |
| Worst-Case Customer | **NO-GO** | The image-import path writes unescaped filenames into markdown, so importing a default-named macOS screenshot silently corrupts the saved document |
| Resource Auditor | **NO-GO** | Nobody has stated what this release is for, and every observable output of it is indistinguishable from doing nothing |
| Future Me | **NO-GO** | The `SyncDocuments` seam's sole failure mode is a silent, unlogged regression to the document-corruption bug it was built to fix |
| Domain / Data Integrity | **NO-GO** | `closeActiveTab` does not cancel the pending `UpdateContent` debounce, so the cross-document overwrite still reproduces; frontmatter and image-alt destruction are co-blocking |

### What Round 2 established that Round 1 could not

Round 1's corpus could not fail, so markdown fidelity had never been measured. With the corpus wired
to the real serializer, opening and editing a file in the default WYSIWYG mode **rewrites the whole
document**, destroying:

- **YAML frontmatter** — `---\ntitle: …\n---` becomes `***` plus a setext heading. Every Hugo,
  Jekyll, Obsidian and Astro file loses its title, date, tags and draft status.
- **Block-image alt text** — `![Architecture diagram](arch.png)` becomes `![1.00](arch.png)`, because
  the vendored editor overloads the `alt` slot to carry its resize ratio. Stable thereafter, so
  unrecoverable.
- **Unused link reference definitions** — deleted outright.

And the corpus is configured to tolerate the first of these: the frontmatter fixture is named
`.stable.md`, which suppresses the A≠B assertion. A live gate was pointed away from the defect it
would have caught.

### Three findings that are the reviewer's own errors, recorded as such

1. **Hardened a caller, not the boundary.** Containment closed one read primitive while
   `anchor.href` reached `SaveDocument` one file away. The Wails bindings are the trust boundary;
   a single caller was treated as if it were.
2. **Built a fallback to the defective behaviour.** `ensureImplicitDocument` was written as a
   compatibility shim and makes the fix's only failure mode *silent*: the generated Wails binding on
   the build machine already lacks `SyncDocuments`, `bridge.js` optional-calls it without the
   `missing()` warning every other binding uses, and Go then reconstructs the pre-fix ambient
   document. No error, no log, no failing test.
3. **Corrected a false claim with another false claim.** README's "signed `.app`" was replaced with
   "ad-hoc-signed `.app`" on the strength of a neighbouring line, without reading
   `tools/build-macos.sh`, which contains zero `codesign` calls. Two stations disagreed on this; the
   script settles it.

### A gate that cannot fail, again

`newTestBrowser` calls `t.Skip` when no Chrome binary is found, so the **entire e2e suite can vanish
while `go test ./...` still prints `ok`** — the same class as the tautological corpus, sitting
underneath every green reading in this document.

### REVISED VERDICT: **NO-GO** (unchanged)

Confidence that shipping `c90b25c` as a non-beta release is right: **1/10**, unchanged from Round 1.
The reasons changed completely — the Round 1 blockers are genuinely closed — but the candidate
acquired no evidence of readiness, and measurement that was previously impossible revealed
document-destroying behaviour in ordinary use.

### Convertibility conditions, Round 3

1. `closeActiveTab` cancels the pending push; no debounced write can outlive its document.
2. Link hrefs restricted to a scheme allowlist; a CSP added; every binding reachable from a script
   foothold enumerated rather than one caller hardened.
3. `SyncDocuments` absence fails loud; `ensureImplicitDocument` deleted so empty state fails closed;
   a test asserts the generated binding exports every method `bridge.js` calls.
4. Frontmatter preserved across an edit. This is the product's core promise and the most common
   real-world markdown shape.
5. Image alt text preserved rather than replaced by the editor's resize ratio.
6. Image filenames escaped when written into markdown.
7. The frontmatter fixture renamed to `.canonical.md` so the corpus asserts fidelity rather than
   tolerating its loss.
8. `newTestBrowser` fails rather than skips when Chrome is absent.
9. README's signing claim corrected against the script, not against a neighbouring line.
10. **The release driver stated.** Not a code condition and not answerable by remediation: one
    station's blocking issue is that nobody has said what this release is for, and no amount of
    fixing converts it.

### Project-lead summary

Round 2 fixed everything Round 1 asked for, verified it, and still returns NO-GO — because the
newly-working gate revealed that opening and editing an ordinary markdown file destroys its
frontmatter, and because a `javascript:` link reaches the file-writing bindings.

### Root-cause clusters

1. **Vendored model** (#2, #3, #4, #11) — the editor parses to a document model and re-serializes;
   anything unrepresentable is lost. *This is the release's defining risk and no patch closes it.*
2. **Control not exercised** (#1, #5) — security controls shipped with no test. Both now have one.
3. **No recorded state** (#8, #9) — nothing identifies a build or survives a failure.
4. **No enforced pipeline** (#7, #12) — every gate hand-run; the artifact drifted two rounds stale.
5. **Fix introduced defect** (#6) — a data-corruption fix that corrupted data differently.

### The one fix

For cluster 1 there is no fix at this layer. The leverage point is the editing engine itself: either
a CommonMark-faithful schema, or an architecture where WYSIWYG edits patch the original source text
rather than replacing it with a re-serialization. **Only the second eliminates the class.**

### Acceptable risks, each justified

- **Unsigned binaries (#14)** — no Apple Developer account; explicitly out of budget. Not a defect
  and not convertible by engineering. Disclosed in README with corrected macOS 15+ instructions.
- **Fidelity rewriting (#2, #3, #4, #11)** — accepted by explicit maintainer decision with
  disclosure as the mitigation. Justified by sequencing: replacing the editing engine is a larger
  piece of work than this release, and users are now told before they lose anything.
- **No staleness check (#10)** — disclosed in Known limitations. Deferred, not dropped; it was
  carried unjustified across three rounds, which is recorded here as a process failure.
- **No CI (#12), no logging (#9), no bundle checksums (#15)** — backlog. Each is real, none is
  reachable by this release's remaining budget, and all are now recorded rather than implied.

**YES — on the gate's own terms.** Cluster 1 is a data-integrity defect in the product's core
promise, and the gate cannot clear it. It was overridden by the decision below.
